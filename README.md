# Digital Products Platform

E-commerce platform for selling digital products (PDFs, guides, learning materials).
Bachelor's thesis project, 2025–2026.

## About

Authors upload and sell digital files. Users buy and download them through a personal dashboard.
Access is controlled — only buyers can download.

## Tech stack

- **Frontend**: React + TypeScript + Vite
- **Backend**: Node.js + Express (REST API)
- **Database**: PostgreSQL
- **Auth**: JWT + bcrypt
- **File uploads**: Multer
